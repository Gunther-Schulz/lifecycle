# The design round's MAP — pieces, seams, and every input placed (2026-09-19)

**Written at the round desk (fable, operator-delegated 2026-09-19 first-hand;
brief: the decision-round directive, addendum 9). This is the round's step 1
per addendum 5's execution form: the map drawn as data BEFORE any decision,
every input placed as an edge status. The Begehung's yield (rounds 3-4,
12 findings, booked 2026-09-19) is folded in — addendum 9's sequencing.**

**The invariant this map instantiates:** every persisted thing resolves to a
registered kind AND every judgment moment resolves to a registered seam — a
moment with no seam is a finding. **An edge owes four parts:** an observable
TRIGGER · a QUESTION posed with the relevant state in front · a TYPED SLOT
with closed vocabulary whose absence is computable · the slot's own NEXT STEP.
**The worked example and grading standard is the item→done move** (trigger:
the close verb; question: the reason; slot: closed grade vocabulary +
closed-ref; next step: the body moves; observer: the verb itself; checks:
conservation + done-home).

**Status vocabulary:** BUILT / PARTIAL / MISSING / DECLINED-with-reason.
A `⚑` marks a status the Begehung's yield moved.

**This document is the round's working map. Frame point 4 (the map as DATA —
edges in the declaration, `audit` failing on a dangling edge, the banner
rendering position) is itself one of this round's design questions (D-6
below), not something this file claims to be.**
